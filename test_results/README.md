# HFIP – Test Results

This folder contains real-world pipeline test results generated by `tests/real_world/run_real_world.py`.

## Files

| File | Description |
|------|-------------|
| `YYYY-MM-DD_HH-MM_results.json` | Full JSON dump of all case results |
| `YYYY-MM-DD_HH-MM_results.csv` | CSV for spreadsheet analysis |
| `YYYY-MM-DD_HH-MM_report.md` | Human-readable Markdown report |
| `latest_report.md` | Symlink / copy of the most recent report |

## How to regenerate

```powershell
cd hfip
& "C:/Program Files/Python313/python.exe" tests/real_world/run_real_world.py
```
